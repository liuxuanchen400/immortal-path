# 仙途抉择

一个基于文字选择的修仙游戏，让玩家体验从杂役弟子到飞升成仙的修仙之路。

## 游戏特色

- 水墨风格的界面设计
- 多重修炼路线选择
- 随机事件系统
- 社交关系网络
- 多结局系统

## 在线游玩

访问 [https://xianchenduo.github.io/immortal-path](https://xianchenduo.github.io/immortal-path) 即可开始游戏。

## 本地运行

1. 克隆仓库：
```bash
git clone https://github.com/xianchenduo/immortal-path.git
```

2. 进入项目目录：
```bash
cd immortal-path
```

3. 使用任意 HTTP 服务器运行项目，例如 Python 的简单 HTTP 服务器：
```bash
python -m http.server 8000
```

4. 在浏览器中访问 `http://localhost:8000`

## 技术栈

- HTML5
- CSS3
- JavaScript (原生)
- GitHub Pages (部署)
